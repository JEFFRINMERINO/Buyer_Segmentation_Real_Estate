# 📸 Dashboard Preview

The Streamlit application provides six interactive pages for exploring buyer segmentation, investment behavior, geographic patterns, prediction, and model performance.

### 🏠 1. Home — Executive Dashboard

Provides an overview of the real estate buyer dataset through key performance indicators and executive-level insights.

### 📊 2. Buyer Segmentation

Explores the identified buyer segments using clustering analysis, segment distributions, and interactive visualizations.

### 💰 3. Investor Behavior

Analyzes investment patterns, acquisition purpose, financing behavior, referral channels, and buyer characteristics.

### 🌍 4. Geographic Analysis

Examines buyer distribution and investment behavior across countries and regions.

### 🤖 5. Predict Buyer Segment

Allows users to enter a new buyer profile and predict the corresponding buyer segment using the trained clustering model.

### 📈 6. Model Performance

Presents clustering evaluation results and model performance metrics used to assess the quality of the segmentation.

# 🎯 Business Problem

Real estate companies often treat all buyers similarly despite significant differences in investment motivation, financing dependency, geographic preferences, portfolio size, and customer satisfaction.

This project uses **unsupervised machine learning** to discover hidden buyer segments and transform them into actionable investment intelligence.

# 👥 AI-Generated Buyer Segments

The K-Means clustering model identifies three distinct buyer segments based on behavioral and investment-related features.

| 🏷️ Segment | 📌 Characteristics |
| --- | --- |
| 🟢 First-Time Buyers | Younger buyers with stronger financing dependence and personal-use characteristics |
| 🟣 Corporate Investors | Buyers associated with larger portfolios and investment-oriented behavior |
| 🔵 Global Investors | Investment-focused buyers with higher transaction and investment values |

> **Note: ** Segment names are descriptive interpretations of the clusters generated by the machine learning model. They are not predefined labels.

# 📏 Model Evaluation

The clustering quality is validated using multiple evaluation metrics.

| 📊 Metric               | 🎯 Purpose                     |
| ----------------------- | ------------------------------ |
| Silhouette Score        | Cluster separation quality     |
| Davies–Bouldin Index    | Cluster compactness            |
| Calinski–Harabasz Score | Overall clustering performance |
