# Machine Learning Based Buyer Segmentation and Investment Profiling for Real Estate Market Intelligence

## Project Overview

This project develops an AI-driven buyer segmentation and investment profiling system for **Parcl Co. Limited** as part of the **Unified Mentor internship**.

The objective is to identify hidden customer segments using unsupervised machine learning techniques and generate actionable investment intelligence for the real estate market.

## Problem Statement

Real estate companies often treat all buyers similarly despite significant differences in investment motivation, financing behavior, geographic preferences, and purchasing patterns.

This project aims to:

* Identify distinct buyer segments
* Analyze investment behavior across demographics
* Understand geographic investment trends
* Evaluate financing and acquisition patterns
* Support targeted marketing and investment strategies

## Objectives

* Perform comprehensive data cleaning and preprocessing
* Conduct exploratory data analysis
* Engineer meaningful buyer and investment features
* Implement K-Means and Hierarchical clustering
* Evaluate cluster quality using Elbow and Silhouette methods
* Generate business-oriented buyer personas
* Build an interactive Streamlit dashboard
